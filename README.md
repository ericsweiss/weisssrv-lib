# weisssrv-lib

Shared CI templates, lint configurations, scripts, and the project CLI consumed by
[weisssrv](https://git.ericsweiss.com/eric/weisssrv) and projects generated from
[weisssrv-project-template](https://git.ericsweiss.com/eric/weisssrv-project-template).

Consumers pin a release tag; see docs/ for the include and versioning contract.
